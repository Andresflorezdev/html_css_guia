# Guía práctica de HTML y CSS

Esta carpeta tiene una guía progresiva para aprender a construir una página web con una base sólida, semántica y lista para crecer.

## Estructura

- `html/01-estructura-basica.html`: anatomía mínima de una página HTML.
- `html/02-secciones-semantic.html`: uso de `header`, `nav`, `main`, `section`, `article` y `footer`.
- `html/03-pagina-completa.html`: versión más completa con bloques de contenido y un ejemplo profesional.
- `html/04-header-parte.html`: ejemplo aislado solo de la parte `header`.
- `html/05-body-main-parte.html`: ejemplo aislado de `body/main` con secciones.
- `html/06-footer-parte.html`: ejemplo aislado solo de `footer`.
- `html/07-nav-parte.html`: ejemplo aislado de la navegación `nav`.
- `html/08-pagina-unida-manual.html`: página final unida manualmente por bloques (sin importar HTML).
- `html/09-para-que-sirve-cada-bloque.html`: explicación clara de para qué sirve `header`, `nav`, `main`, `section`, `article` y `footer`.
- `html/10-etiquetas-html.html`: referencia práctica de etiquetas HTML comunes.
- `html/11-formulario-estatico.html`: ejemplo de formulario HTML solo estático (sin lógica JS/backend).
- `css/01-estilos-basicos.css`: estilos iniciales para entender color, espacio y tipografía.
- `css/02-estilos-completos.css`: estilos completos con variables, tarjetas, grid, responsive y ejemplos más avanzados.
- `index.html`: versión final lista para abrir en el navegador.
- `styles.css`: archivo de compatibilidad que importa la hoja principal.

## Formato del mini curso

- Cada archivo de `html/` explica una etapa distinta.
- También hay archivos por piezas (`header`, `nav`, `main`, `footer`) para enseñar por partes.
- Se añadieron archivos de apoyo para explicar bloques, etiquetas y formulario estático.
- Cada archivo de `css/` muestra cómo pasar de estilos básicos a un sistema más sólido.
- La página principal incluye explicación, ejemplos y ejercicios para practicar.

## Qué enseña

- Estructura HTML limpia y semántica.
- Separación real entre contenido y presentación.
- CSS con variables para mantener consistencia.
- Explicación práctica de qué hacen `margin`, `padding`, `border`, `color`, `background` y `layout`.
- Diseño responsive con grid y flexbox.
- Buenas prácticas visuales: jerarquía, contraste, espacios y legibilidad.
- Un patrón simple para pensar una página como componentes reutilizables.
- Ejemplos reales de tarjetas, formularios y layouts.
- Ejercicios prácticos por nivel para que no quede solo en teoría.

## Cómo usarla

1. Abre primero los archivos de `html/` para entender la estructura.
2. Luego mira los archivos de `css/` para ver cómo se da estilo a cada parte.
3. Finalmente abre `index.html` para ver todo unido. La hoja principal está en `css/02-estilos-completos.css`.
4. Si quieres enseñar por bloques, usa `04`, `05`, `06` y `07`; luego abre `08-pagina-unida-manual.html` para ver el ensamblaje final.

### Atajo útil

> [!TIP]
> En VS Code puedes ver este README como un preview con Ctrl+Shift+V.

## Sugerencia de estudio

1. Copia la estructura HTML sin estilos.
2. Agrega clases solo cuando realmente las necesites.
3. Aplica CSS por bloques: layout, tipografía, componentes y responsive.
4. Vuelve a leer el resultado y pregunta si cada etiqueta tiene un motivo claro para existir.
5. Resuelve los ejercicios de cada archivo antes de pasar al siguiente.
