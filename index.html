Resumen

Qué vas a aprender

HTML organiza el contenido y CSS lo convierte en una interfaz clara, legible y visualmente consistente.

  • Semántica útil.
  • Componentes reutilizables.
  • Diseño adaptable a móvil y escritorio.

HTML

Etiquetas que sí importan

header

Encabezado de la página o de una sección. Suele llevar el título, una descripción o acciones principales.

nav

Bloque de navegación. Aquí van los enlaces que ayudan a moverse por el contenido o por el sitio.

main

Contenido principal de la página. Debe existir uno solo por documento para no confundir la estructura.

section

Agrupa contenido relacionado dentro de una misma temática. Es ideal para dividir la página en bloques claros.

article

Representa una pieza independiente de contenido: una tarjeta, noticia, post o elemento reutilizable.

footer

Zona final de la página. Suele contener enlaces secundarios, copyright o información adicional.

Ejemplo

Estructura base bien armada

Piensa en una página como partes simples: arriba va el encabezado, en el medio el contenido y abajo el pie.

<body>
    <header>
        <h1>Título</h1>
    </header>

    <main>
        <p>Aquí va el contenido principal.</p>
    </main>

    <footer>
        <p>Información final.</p>
    </footer>
</body>

Criterio senior

Regla práctica

  • No uses div por costumbre si existe una etiqueta semántica mejor.
  • Separa contenido, presentación y comportamiento.
  • Repite patrones visuales con clases, no con estilos sueltos.
  • Si un bloque tiene sentido por sí solo, probablemente sea un article.

CSS

Cómo se ve un CSS más profesional

Explicación

Qué hace cada grupo de propiedades

Box model

margin separa elementos, padding crea espacio interno y border dibuja el borde visible.

Color y fondo

color cambia el texto y background pinta el fondo o una capa visual del bloque.

Tipografía

font-size, line-height y font-weight controlan lectura, ritmo y jerarquía.

Layout

display: grid y display: flex organizan columnas, filas y alineación de elementos.

01

Variables

Centralizan colores, sombras y tamaños para que el diseño sea consistente y fácil de ajustar.

02

Layout

Grid y flexbox ayudan a organizar bloques de contenido sin depender de trucos frágiles.

03

Responsive

El diseño debe adaptarse a pantallas pequeñas, medianas y grandes sin romperse.

04

Estados

Hover, focus y otras interacciones hacen que la interfaz se sienta más clara y usable.

Más ejemplos

HTML y CSS aplicados a casos reales

HTML

Tarjeta de contenido

<article class="card">
  <h3>Título</h3>
  <p>Descripción corta del contenido.</p>
  <a href="#">Leer más</a>
</article>

Sirve para noticias, productos, cursos o cualquier bloque independiente.

HTML

Formulario básico

<form>
  <label for="email">Correo</label>
  <input id="email" type="email" />
  <button type="submit">Enviar</button>
</form>

Útil cuando quieres recolectar datos sin perder accesibilidad ni orden semántico.

CSS

Diseño de tarjeta

.card {
  background: white;
  border: 1px solid #eadac0;
  border-radius: 18px;
  padding: 1.5rem;
  box-shadow: 0 18px 40px rgba(56, 40, 16, 0.12);
}

Combina superficie, borde, radio y sombra para dar sensación de bloque reutilizable.

CSS

Layout responsive

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

Hace que los elementos se acomoden solos según el ancho disponible.

Ejemplos extra (más reales)

HTML

Header con logo y menú

<header class="topbar">
  <h1>Mi Marca</h1>
  <nav>
    <a href="#">Inicio</a>
    <a href="#">Servicios</a>
    <a href="#">Contacto</a>
  </nav>

Patrón típico para sitios personales, portafolios y landing pages.

HTML

Sección de tarjetas

<section class="cards">
  <article>Tarjeta 1</article>
  <article>Tarjeta 2</article>
  <article>Tarjeta 3</article>
</section>

Sirve para mostrar servicios, productos, features o posts.

CSS

Menú horizontal con flex

.topbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Un patrón simple y muy usado para alinear logo y navegación.

CSS

Botón con estado hover

.btn {
  padding: 0.75rem 1rem;
  border-radius: 10px;
  background: #c26d12;
  color: white;
}

.btn:hover {
  background: #9a4f07;
}

Aporta feedback visual claro cuando el usuario interactúa.

Práctica

Ejercicios para aprender de verdad

Ejercicio 1

Solo HTML

Crea una página con header, nav, main, tres section y un footer.

  • Usa un título principal y dos subtítulos.
  • Agrega una lista y una imagen con texto alternativo.
  • Revisa que el contenido tenga sentido semántico.

Ejercicio 2

Solo CSS

Diseña una tarjeta simple con fondo claro, borde, sombra y espaciado interno.

  • Cambia la tipografía y la altura de línea.
  • Aplica hover a un enlace o botón.
  • Haz que el bloque se vea bien en móvil.

Ejercicio 3

Mini proyecto

Construye una landing page con hero, beneficios, ejemplos y contacto.

  • Usa grid para organizar las tarjetas.
  • Usa variables CSS para definir colores.
  • Agrega una sección final con un CTA claro.

Checklist

Antes de publicar

  • Solo existe un main en la página.
  • Los títulos siguen un orden lógico.
  • Los enlaces tienen un destino claro.
  • Los colores mantienen buen contraste.
  • Los espacios entre bloques son consistentes.
  • El contenido funciona también en móvil.

Hecho para aprender HTML y CSS con una base más cercana a un proyecto real.
