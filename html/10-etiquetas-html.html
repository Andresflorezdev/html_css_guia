Etiquetas HTML + ejemplos de uso

Aquí no solo ves la etiqueta: también tienes ejemplos reales para copiar y practicar. Incluye qué significan símbolos como &lt; y &gt;.

Entidades HTML

¿Qué significa &gt; y por qué se usa?

En los ejemplos de código usamos entidades HTML para mostrar símbolos sin que el navegador los interprete como etiquetas reales.

  • &amp;lt; muestra <
  • &amp;gt; muestra >
  • &amp;amp; muestra &
  • &amp;quot; muestra "
&lt;h1&gt;Hola&lt;/h1&gt;

Eso se ve en pantalla como: <h1>Hola</h1>.

Semánticas

Estructura de página

<header>

Encabezado del sitio o de una sección.

<nav>

Zona de enlaces de navegación.

<main>

Contenido principal de la página.

<section>

Agrupa contenido por tema.

<article>

Bloque independiente: post, tarjeta, noticia.

<aside>

Contenido complementario o lateral.

<footer>

Pie de página o cierre de sección.

Ejemplo semántico

Layout base con etiquetas correctas

<body>
  <header>...</header>
  <nav>...</nav>
  <main>
    <section>
      <article>...</article>
    </section>
    <aside>...</aside>
  </main>
  <footer>...</footer>
</body>

Texto

Etiquetas de contenido

<h1>...<h6>

Títulos con jerarquía.

<p>

Párrafos de texto.

<strong>

Texto importante.

<em>

Énfasis de lectura.

<small>

Texto secundario o legal.

<mark>

Resalta una parte del texto.

<blockquote>

Cita en bloque.

<code>

Fragmento de código en línea.

<pre>

Texto preformateado (código con saltos).

Ejemplo de texto

Combinación de etiquetas de contenido

<h2>Título del artículo</h2>
<p>Este texto tiene <strong>importancia</strong> y también <em>énfasis</em>.</p>
<p><small>Publicado el 14 de abril</small></p>
<blockquote>Aprender haciendo es la mejor forma.</blockquote>

Listas

Listas y agrupación

<ul>

Lista desordenada (viñetas).

<ol>

Lista ordenada (números).

<li>

Elemento de una lista.

<dl>

Lista de definiciones.

<dt>

Término en una definición.

<dd>

Descripción del término.

Ejemplo de listas

Ordenadas, desordenadas y de definición

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<ol>
  <li>Estructura</li>
  <li>Estilos</li>
</ol>

<dl>
  <dt>Header</dt>
  <dd>Parte superior de la página</dd>
</dl>

Media

Imágenes, audio y video

<img>

Muestra imágenes.

<figure>

Agrupa contenido visual.

<figcaption>

Texto descriptivo de una figura.

<audio>

Reproductor de audio.

<video>

Reproductor de video.

<source>

Fuente alternativa de audio/video.

<iframe>

Inserta contenido externo (mapas, videos).

Ejemplo media

Figura con descripción

<figure>
  <img src="foto.jpg" alt="Vista de la ciudad">
  <figcaption>Ciudad al atardecer</figcaption>
</figure>

Tablas

Etiquetas para datos tabulares

<table>

Contenedor principal de tabla.

<thead>

Encabezado de la tabla.

<tbody>

Cuerpo de la tabla.

<tr>

Fila de tabla.

<th>

Celda de encabezado.

<td>

Celda de dato.

<caption>

Título de la tabla.

Ejemplo tabla

Tabla básica de precios

<table>
  <caption>Precios</caption>
  <thead>
    <tr><th>Plan</th><th>Precio</th></tr>
  </thead>
  <tbody>
    <tr><td>Básico</td><td>$10</td></tr>
  </tbody>
</table>

Formularios

Etiquetas para capturar datos

<form>

Contenedor del formulario.

<label>

Etiqueta de campo.

<input>

Campo de entrada.

<textarea>

Campo de texto largo.

<select>

Lista desplegable.

<option>

Opción dentro de select.

<button>

Botón de acción.

<fieldset>

Agrupa campos relacionados.

<legend>

Título de un fieldset.

Ejemplo formulario

Formulario corto

<form>
  <fieldset>
    <legend>Contacto</legend>

    <label for="correo">Correo</label>
    <input id="correo" type="email" />

    <label for="mensaje">Mensaje</label>
    <textarea id="mensaje"></textarea>

    <button type="submit">Enviar</button>
  </fieldset>
</form>
